# facebook-clone

This is a Next.js(https://nextjs.org/) project bootstrapped with create-next-app(https://github.com/vercel/next.js/tree/canary/packages/create-next-app). Getting Started First, run the development…

**Stack** : Next.js, React, Tailwind CSS

## Démarrage

```bash
npm install   # installer les dépendances
npm run dev   # serveur de développement
npm start   # démarrer
npm run build   # construire
npm run lint   # lint
```
